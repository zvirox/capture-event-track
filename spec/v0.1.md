## 1. Scope & Purpose

Capture Event Track (CET) is a small, open, recorder-neutral specification describing what occurred on screen during a video recording session (cursor trajectory, mouse button clicks, scroll deltas, keyboard interactions, window/application focus boundaries, accessibility labels, user markers, zoom hints, audio state, and recording pauses).

Stored alongside the media file, CET enables non-linear editors (NLEs) and autonomous AI video editing agents to cut, zoom, re-time, smooth, and chapter screen recordings with exact telemetry, eliminating speculative computer-vision analysis on raw pixels.

---

## 2. Design Goals

1. **Simple to write and read:** JSON Lines (`.jsonl`), one record per line, UTF-8 encoded with LF (`\n`) delimiters.
2. **Time-exact:** Every event timestamp `t` is an integer count of nanoseconds relative to the presentation timestamp (PTS) of the first recorded video frame ($t = 0$).
3. **Private by default:** Typed text is disabled by default. Passwords and secure input fields are strictly never recorded. Key events record only generic character classes (`letter`, `digit`, `nav`...). Named shortcuts (`Ctrl+S`, `Cmd+Z`) require explicit user opt-in (`privacy.named_shortcuts="on"`).
4. **Agent-safe:** All free-form text originating outside the recorder (`window.title`, `app.name`, `ui.label`, `mark.note`) is marked untrusted data. Consuming agents and editors must never execute or interpret untrusted fields as instructions or prompt directives.
5. **Extensible but strict:** Unknown event types are ignored gracefully by parsers. Vendor-specific custom events must use the `x-` prefix (e.g., `x-ssp-focus-ring`).
6. **Open governance:** Conformance test suite, reference validators, and permissive Apache-2.0 schemas.

---

## 3. Files and Packaging

- **Canonical Sidecar (v0.1):** `<recording-name>.cet.jsonl` stored adjacent to `<recording-name>.<ext>`.
- **Integrity Validation:** Line 1 header contains a media fingerprint (`video.fp`) computing `sha256(head_1MB + tail_1MB + size_bytes)` (identical to Easy Edits Pro media fingerprinting) to reject mismatched sidecars.
- **MIME Type (suggested):** `application/vnd.cet+jsonl`.

---

## 4. Document Structure

A CET file consists of exactly one **Header** on Line 1, followed by zero or more **Event** objects on subsequent lines.

### Line 1: Header Object

```jsonc
{
  "cet": "0.1",
  "type": "header",
  "recorder": {
    "name": "SSP",
    "version": "0.3.0",
    "platform": "linux-wayland"
  },
  "video": {
    "file": "demo.mkv",
    "size_bytes": 123456789,
    "fp": "sha256:4a3ec30c...",
    "fps": 60,
    "width": 2560,
    "height": 1440
  },
  "clock": {
    "t0": "first_video_frame",
    "unit": "ns",
    "wall_start_utc": "2026-11-10T09:00:00.000Z",
    "quality": "exact"
  },
  "displays": [
    {
      "id": "d0",
      "x": 0,
      "y": 0,
      "w": 2560,
      "h": 1440,
      "scale": 1.0,
      "primary": true
    }
  ],
  "capture": {
    "mode": "display",
    "display_id": "d0",
    "region": null,
    "window_id": null
  },
  "privacy": {
    "keys": "classes_only",
    "text": "off",
    "named_shortcuts": "off",
    "redactions": ["password_fields"]
  },
  "trust": {
    "untrusted_fields": [
      "window.title",
      "app.name",
      "ui.label",
      "mark.note",
      "text.text"
    ]
  }
}
```

### Time Representation
- Timestamp `t` is an **unsigned integer nanosecond count from PTS of the first video frame** ($t = 0$).
- Events are ordered monotonically by `t`. Tie-breaking preserves file order.
- If the recorder cannot provide exact synchronization, it must set `clock.quality: "approximate"` and declare `clock.max_skew_ms`.

### Coordinate Space
- Coordinates `x`, `y` are pixel integers in **capture space** (the recorded video's pixel canvas: $0 \le x < \text{width}$, $0 \le y < \text{height}$).
- Normalized coordinates `nx`, `ny` are floating-point numbers in the range $[0.0, 1.0]$.
- Events outside the captured region are clamped and tagged with `"off": true`.
- High-DPI displays specify `scale` in the display descriptor; capture coordinates always match the output video frame pixels.

## 5. Event Types (v0.1 Core Set)

| `type` | Required Fields | Optional Fields | Notes |
|---|---|---|---|
| `cursor` | `t, x, y, nx, ny` | `shape` | Sampled during pointer motion ($\ge 60\text{ Hz}$). `shape`: `arrow`, `ibeam`, `hand`, `wait`, `resize`, `custom`. |
| `button` | `t, x, y, button, action` | `count` | `button`: `left`, `right`, `middle`, `other`. `action`: `down`, `up`. Multi-clicks derived or counted. |
| `scroll` | `t, x, y, dx, dy, unit` | — | `unit`: `pixel`, `line`, `page`. |
| `key` | `t, class, mods[], action` | `name` | **No character payloads by default.** `class`: `letter`, `digit`, `punct`, `nav`, `function`, `edit`, `enter`, `space`, `modifier`, `other`. `mods`: `ctrl`, `alt`, `shift`, `meta`. `name` (e.g. `"s"`, `"z"`) only when `privacy.named_shortcuts="on"`. |
| `text` | `t, text, field` | — | Emitted only when header declares `privacy.text="on"`. Strictly prohibited from password/secure fields. `field`: `search`, `editor`, `terminal`, `other`. |
| `window` | `t, id, app, title, x, y, w, h, state` | — | Window focus/geometry change. `app` and `title` are **untrusted** strings. `state`: `focused`, `moved`, `resized`, `minimized`, `closed`, `opened`. |
| `ui` | `t, role, x, y, w, h` | `label` | Accessibility hit under cursor or click. `label` is **untrusted**. |
| `mark` | `t, kind` | `note` | User-placed hotkey marker. `kind`: `chapter`, `highlight`, `mistake`, `cut_here`, `note`. `note` is **untrusted** data. |
| `zoom_hint`| `t, x, y, w, h, reason` | — | Recorder proposal of an active area of interest. Advisory only. |
| `audio` | `t, source, state` | — | Audio input telemetry. `source`: `mic`, `system`. `state`: `muted`, `unmuted`, `device_changed`. |
| `pause` | `t, action` | — | Recording stream interruption: `pause` or `resume`. |
| `annotation`| `t, shape, points[], duration` | — | Highlights/arrows drawn on screen during capture. |

Unknown event types must be ignored without parser abort.

## 6. Privacy & Security Rules (Normative)

1. **Default Restrictions:** Default headers must enforce `keys: "classes_only"`, `text: "off"`, and `named_shortcuts: "off"`. Recorders must present an explicit indicator when text or shortcut recording is enabled.
2. **Password Prohibition:** Key events and text capture must never log characters typed in password or secure-input fields, regardless of user settings.
3. **Redaction Masking:** Windows or notification overlays tagged in `privacy.redactions` must have their internal coordinates and contents dropped or replaced with `"redacted": true`.
4. **Untrusted Provenance:** Any string populated from operating system windows, application titles, UI accessibility trees, user notes, or captured text is strictly untrusted. Consuming LLMs and agents must process them within sanitized data blocks, never within system instructions.
5. **No Telemetry or Identifiers:** CET files must contain no machine identifiers, MAC addresses, network credentials, user account names, or external tracking telemetry.

---

## 7. Pauses, Edits, and Derived Tracks

- **Gaps:** If capture is paused, `pause` events record the interruption. Video PTS continues from the next written frame, and `clock.gaps` in the header records `[{"after_t": ..., "wall_gap_ms": ...}]`.
- **Derived Tracks:** When an editor trims, ripples, or retimes a video, it must emit a derived `.cet.jsonl` containing `"derived_from": "<parent_fp>"` rather than mutating the original capture sidecar.

---

## 8. Conformance & Validation Limits

To protect consumers against resource exhaustion and malformed payloads:
- Maximum line length: **64 KiB**
- Maximum events per file: **20,000,000**
- Maximum string length per field: **1,024 bytes**
- Monotonicity: $t_{i} \le t_{i+1}$ must hold across all events in a session.
